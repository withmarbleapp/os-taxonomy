Connect Claude

  1. Install Claude Code using the official setup guide ↗.
  2. Open a terminal and run claude auth login. Sign in with your Claude subscription.
  3. Come back and select Check again.

Connect Codex

  1. Install Codex CLI using the official setup guide ↗.
  2. Open a terminal and run codex login. Choose your ChatGPT account.
  3. Come back and select Check again.

If you’re already signed in, check your subscription’s usage allowance and try again.
