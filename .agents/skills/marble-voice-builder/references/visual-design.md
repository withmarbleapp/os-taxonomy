# Voice-led visual experience

Keep the established Marble font and tactile component roles in
[component-styling.md](component-styling.md). The supplied host already has the
walkie-talkie, menu, text alternative, captions and word-help treatment. Reuse
those. The lesson renderer composes the phenomenon, not another product UI.

The opening poses a central question with meaningful artwork and a single start
action. After entry, use one small title and one short prominent instruction.
Feedback replaces that instruction. Full spoken text appears only when captions
or text mode is chosen; it must not silently replace the scene label. Keep adult
setup, provider details and contract inspection in the menu/adult note.

Use Baloo 2, sentence case, outlined tactile buttons with concise action labels,
readable contrast, and generous direct manipulation targets. Use technical terms
only when useful, define them briefly on demand, and never put definition triggers
inside controls. The copied component reference and `assets/marble-ui.css` give
actual sizing/roles, not permission to clutter a scene with labels.

Choose a representation that preserves the relationships the child needs.
When depth, occlusion, illumination or viewpoint matters, use Three.js and the
crafted cel-shaded model style, not a flat infographic substituting for spatial
interaction. For equal area, grouping or fraction parts, a planar model may be
more appropriate. Visual polish does not compensate for wrong geometry or a
misleading causal relationship.

Test dense supports, long-but-valid translated instructions, editable fields,
word help and the walkie-talkie at the intended device sizes. Add keyboard/text
alternatives for essential pointer/sound interactions. Do not assume precise
dragging or desktop hover is available. Keep one coherent scene; avoid a generic
sidebar dashboard or a stack of instructional cards.

The reference examples contain topic-specific visual exceptions. Their number
fields, horizon inset and older layout choices are not universal requirements.
