## Current worked service resources

The [City of Toronto's actual waste instructions](https://www.toronto.ca/services-payments/recycling-organics-garbage/houses/set-out-tips/) support a garbage/organics case: adults arrange suitable collection and accessible, correctly placed bins, while users help prevent litter and obstruction. Primary learners explain or model the relationship; no real waste handling or collection-truck interaction is required. The current page explicitly separates residential recycling responsibility from the City from January2026. The task does not teach that the City operates every waste stream or that all dwelling/collection types have identical rules.

The City's [Toronto Public Library agency entry](https://www.toronto.ca/city-government/accountability-operations-customer-service/city-administration/city-managers-office/agencies-corporations/agencies/toronto-public-library/) identifies the actual public service provider. The [library's borrowing instructions](https://tpl.ca/help/borrowing-materials/) support a borrower-duty example involving returning ordinary books so others can use them. An adult supplies the relevant rules; no account, card, private borrowing history or fixed universal loan period is required. Some materials have different return locations and periods, so the protocol retains those limits rather than inventing one rule for every item.

For another community, an adult prepares current attributed cards from the actual provider. Toronto is a worked resource example, not evidence that every municipality has the same service organization. Source-specific civic facts remain accurate and visible without creating a younger duplicate of the whole council/elections/funding claim.
