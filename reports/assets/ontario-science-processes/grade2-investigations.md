# Grade 2: animals, materials, movement, air and water

Use the [common process records](shared-process-records.md) with all four actual contexts below. These are original classroom protocols. No result is pre-filled. Research includes the pupil's actual records and the selected Ontario 2022 animal/material/movement/air-and-water content accounts; an adult provides the relevant short source sections with their source identity, rather than treating a search-result heading as evidence. The official curriculum is a source of questions and explanatory requirements, not a claim that it validated these particular activities.

## B — A feeding-tool model

Question: does the shape of a model tool change how it can collect different model foods? Use large paper food pieces, a shallow tray, a blunt adult-approved scoop and large rounded classroom tongs. No actual animal, food, sharp beak model or small choking item is used. Observe the tools closely, naming a same and a different visible feature. Predict a result with a reason. Keep the number/size of model pieces, tray, transfer distance and time the same; compare the actual number transferred with each tool and repeat. Retain failed pickups, not only successes. Compare the model's shape/function with the selected animal-feature account. The model tests the tools in this setup; it does not prove the feeding success, diet or development of an actual species. Changed case: larger flat food pieces; predict, then test rather than assume the first winner must win again.

## C — Floating and material properties

Question: which of five large, adult-approved clean objects float or sink in a shallow tray of room-temperature water? Choose objects with different observable materials/shapes; first predict each outcome, then lower each gently in the same way. Keep the water depth and container the same and record actual float/sink/unclear results, including a surprise. Close observation includes visible shape/texture and same/different comparisons. A second comparable trial checks the record. Floating does not prove an object is light in every sense; a conclusion about these objects is not a general density calculation. Changed case: reshape the SAME piece of approved modelling material into a broad hollow form, keeping its amount unchanged, and retest without claiming the result in advance. This is an actual shape comparison, not an automatic change of material.

## D — A ramp for a classroom delivery model

Question: how does a model ramp help move the same small classroom load between two low levels? Use a low stable board, a large soft rolling object and a clear tabletop or floor landing zone. No raised furniture, steep launch, people riding, springs or thrown objects. Compare two ramp lengths reaching the same low height, using the same load, start and smooth slow hand movement. Record how far the load is moved along each ramp and describe the effort felt without inventing force measurements. Build two routes for an actual partner's model delivery need, with criteria reach the marked destination and stay inside the safe route. Test both, record a strength and weakness and revise after partner feedback. Changed case: a different floor covering; repeat before claiming the first route still works. The activity does not establish an exact mechanical-advantage ratio.

## E — Water loss with an open or covered container

Question: does covering a shallow container change the amount of water remaining over several classroom days? Use identical stable unbreakable containers with the same initial amount of clean water, one open and one safely covered, away from heat and walkways. No drinking, microbial culture, heated water or mould handling. Mark the initial level and record the actual level/amount at agreed times with the same method; adult disposes/cleans promptly. Compare visible water/condensation when present. A small or unclear change remains an inconclusive result. Sources and actual observations help discuss where water can go; an empty container is not evidence that water ceased to exist. Design a spill-resistant model cover for a classroom display, stating observation/access as well as containment needs; test actual handling only with small safe quantities. Changed case: a different cover opening, keeping the other conditions comparable. Do not infer daily weather or organism survival from this single indoor comparison.

## Integration and communication

Across B/C/D/E, pose at least three own questions, select methods and sources, and make a shared written/drawn project with attributed source notes and firsthand findings. Use a table for the tool/float outcomes and a time record for the water question; use a useful pictogram only for a question supported by the actual counts. Include an observable-feature classification key and labelled drawing where checking the existing whole data claim. Model drawings explain shape/function. Present a result to a younger partner and a concise method/results note to another investigator, using actual science vocabulary. Compare prediction with result, answer with evidence, give one relevant improvement and a changed-case prediction. The common source-assessment contrast and safety observations are part of the programme, not substitutes for these real investigations.
