# Simple machine arrangements: complete claim and source portfolio

Reviewed source-authoring implementation for `mt_vjMAN6sb7z` and D2/D2.3/D2.4. This is one portable conceptual claim, not six nodes or a country/grade/difficulty variant. Main acceptance and downstream publication remain separate; no learner attainment, migration or reset is claimed.

## Complete portable whole claim

Name: **Simple machine arrangements and everyday uses**
Type: CONCEPTUAL. Subject: Science. Domain: Forces & Motion.

Description: Recognise the six conventional simple-machine arrangements—lever, inclined plane, wedge, pulley, wheel and axle, and screw—from their working features, and explain an appropriate everyday function for each. Distinguish an arrangement from the whole object containing it and recognise that the benefit depends on the arrangement; a simple machine need not contain a motor or always reduce the required force.

Complete evidence:

1. Independently name all six arrangements from varied clear pictures or models and point to the defining feature: turning bar/support, sloping travel surface, tapering separating piece, guided rope/wheel, rigidly connected wheel/shaft, and spiral thread.
2. For each category, describe an accurate everyday use and connect the working arrangement to what it helps people do. A list of six tool names without functions is insufficient.
3. Classify fresh clearly depicted cases by their working features rather than colour, position or presence of an electric motor. Explain when an object contains more than one arrangement or its description is insufficient instead of forcing an unsupported single label.
4. Explain the bounded countercases that a fixed pulley changes pulling direction without automatically halving force, and that changing a lever arrangement can change its benefit. Qualitative explanation is enough; no gear ratios, moment formula, numerical mechanical advantage or formal energy vocabulary gate.

Assessment prompt: After studying all six, can the learner identify each arrangement in a fresh set, show its working feature and explain a suitable everyday use? Can they say why a fixed rope wheel can help by changing direction without claiming it always makes the load easier to lift, and why a complex tool can contain several arrangements?

Initial authored context: Ontario7–8. New topic compatibility age guidance is7–8, projected from this actual complete-claim context. No unsupported global7–12 offer is added. This does not assert universal readiness or efficacy.

## Complete teaching guide

Use the existing original six-machine primer, six everyday-use cards, SVG and label-hidden check HTML in PR160 as the study resource. Explain all six with the working feature visible, then have the learner describe the feature and function in their own words. Teach an actual use for each: supported bar moves a selected load; ramp gives a sloped route; tapered wedge separates or holds in the specified case; guided rope wheel changes pulling direction; larger wheel/knob turns a connected shaft; threaded fastener turns to join selected materials. These are diagrams/models, not instructions to handle sharp tools or suspend loads.

Explicitly distinguish the ramp case (object travels along the sloped surface) from the wedge case (the taper moves between or under things). Distinguish a wheel/axle turning together from an independent freely rotating rope wheel. Point to the spiral thread on the screw rather than classifying every metal rod as a screw. A learner may use ordinary language for the feature before acquiring its formal name.

Compare a toy with a motor, a plain sloped board and a fixed pulley: machine categories describe arrangements, not whether a motor is present. Revisit the existing force comparison table only as a declared model: same load and height; fixed pulley direction-only countercase and changed short-arm lever. Do not infer every lever or pulley reduces force, or claim that a machine creates energy.

After study, remove names and captions, shuffle the teaching examples and request independent name/feature/function production. If the learner remembers only a colour or position, teach the feature again and use another example; do not reward the positional guess as understanding. Ask which features would need to be seen if a whole-object photograph is ambiguous.

Then use the actual new original independent SVG `assets/ontario-grade2-machines/independent-six-arrangements.svg`, rendered and visually inspected at 1200×820. It contains six unlabeled structural cards with neutral letters, changed arrangements/proportions and movement arrows. It is an assessment resource, not a promise that an author will later find images. The image was authored from scratch and copies no source figure. Names and functions are kept in this teacher key, not printed on the learner cards.

Teacher key: A lever (bar turns about support to move the load); B inclined plane (object travels up the sloped surface); C wedge (taper separates two model pieces); D pulley (rope passes over a fixed overhead wheel to raise the opposite load); E wheel and axle (larger turning wheel is rigidly connected to the smaller shaft); F screw (spiral thread turns through and joins the selected model pieces). Ask for another everyday use of each and accept an accurate studied example; require a new classification example for transfer, not six newly invented tool functions.

Near misses: an ordinary straight rod without a thread is not a screw just because it is metal; a sloped board used as a travel surface is not classified as a wedge merely because the side outline is triangular; a vehicle wheel does not by itself demonstrate the same lifting-force benefit as the selected wheel-and-axle arrangement. A pair of scissors can include lever and wedge arrangements; do not force one label for the entire compound object.

Assessment full: all six names and working features, each accurate everyday function, fresh feature-based transfer, appropriate compound/insufficient-view treatment, and the bounded fixed-pulley/changed-lever account. Partial: recognises some categories but relies on captions, positions or tool names without the arrangement/function. Gap: treats every device as an electrical machine or cannot distinguish the working arrangements. Correct function with a missing name is a vocabulary need; a wrong mechanism/function requires revisiting the working model. Neither is fixed by supplying the answer during the independent check.

The new guide records only the actual bounded source read with low confidence in its original pedagogy; no old source/confidence flag is inherited as fresh verification. ## Independent overall D2 source portfolio

The new whole claim contributes only one part of D2. The overall source still needs its own movement-and-machine understanding check. The exact public task is:

Give the learner a small ordinary object at a marked starting position and a higher destination represented in a drawing/model. Ask them to describe more than one way it can move or be repositioned, and show the difference between the movement and its resulting position. They can draw or safely move a light tabletop object; a supplied route diagram is not described as their observation.

Offer the actual original direct-lift, ramp, lever and pulley cards, with the existing clearly declared matched-load/height force data. The learner chooses two different useful arrangements for the destination, explains what each helps to do and compares each with the direct-lift case. They must identify the fixed-pulley direction-only countercase and reassess the changed lever, rather than claim all machines lower force. They then explain a different everyday movement/use using another category from the six-type repertoire. Require their own explanation/model and justify one changed-route or changed-arrangement choice.

Full overall evidence: movement and changed position understood; two machine arrangements and their distinct contributions explained; valid comparison with no-machine movement; and justified transfer/countercase. Six names alone, a tally of D2 children or a copied force table is insufficient. Actual Testing whole mastery still requires its goal/prediction/test/record/change/re-test loop; source comparison can use declared model data without awarding it.
