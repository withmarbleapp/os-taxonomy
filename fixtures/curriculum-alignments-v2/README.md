# Synthetic scoped alignment fixtures

These are invented schema-version-2 examples, not official curriculum expectations or learner data. All ages are within the primary-school examples used by this tooling.

The same topic has global age guidance, a separate international framework association, a jurisdiction context and two age intervals in another jurisdiction with different standard memberships. Another topic has intentional jurisdiction age guidance, and a third is unaligned. `normalized.json` and `projection.json` are golden expectations; the latter contains only compatibility fields, not complete topics.

The [version 2 contract](../../docs/curriculum-alignment-contexts-v2.md) documents identity, source membership and read-only commands. Version 1 fixtures remain separately available under `../curriculum-alignments/`.
